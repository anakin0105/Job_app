## О проекте

Консольное приложение для поиска вакансий с платформы **hh.ru**.  
Проект выполнен в двух частях:

- **Часть 1** — Работа с API hh.ru + JSON-хранилище (избранное)
- **Часть 2** — Работа с PostgreSQL (курсовая по базам данных)

## Основные возможности

### 1. JSON-режим (Часть 1)
- Поиск вакансий по ключевому слову
- Сохранение в избранное (JSON-файл)
- Просмотр всех сохранённых вакансий с красивым выводом
- Топ-N вакансий по зарплате
- Сравнение двух вакансий по ID (таблица)
- Поиск по ключевому слову среди избранного
- Удаление вакансий

### 2. PostgreSQL-режим (Часть 2) — **НОВОЕ**
- Автоматическое создание базы данных и таблиц
- Связь таблиц через Foreign Key (`employers` ↔ `vacancies`)
- Загрузка данных **10 крупных компаний** и их вакансий с hh.ru
- Класс `DBManager` с 5 обязательными методами:
  - Список компаний + количество вакансий
  - Все вакансии (компания, название, зарплата, ссылка)
  - Средняя зарплата по всем вакансиям
  - Вакансии с зарплатой выше средней
  - Вакансии по ключевому слову (ILIKE)

## Установка и запуск

1. Клонируй репозиторий и перейди в папку проекта
2. Создай и активируй виртуальное окружение
3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
    ```
4. Создай файл .env (см. .env.example)
5. Установи зависимости:
 ```bash
   python main.py
   ```
