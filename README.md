## О проекте

Консольное приложение для поиска и работы с вакансиями с платформы hh.ru через их публичное API.

### Основные возможности

- Поиск вакансий по ключевому слову
- Сохранение понравившихся вакансий в избранное (JSON-файл)
- Просмотр всех сохранённых вакансий (красивый вывод с эмодзи)
- Топ-N вакансий по зарплате
- Сравнение двух вакансий по ID (таблица с выделением лучшей зарплаты)
- Поиск по ключевому слову среди сохранённых
- Удаление вакансий из избранного
- Полная поддержка пагинации API hh.ru
- Безопасная работа с данными (обработка ошибок, отсутствие дублей по ID)

### Технологии

- Python 3.11+
- Библиотека `requests` — работа с API
- `tabulate` — красивые таблицы в консоли
- `python-dotenv` — конфигурация через .env (базовый URL API)
- `pytest` + `pytest-mock` — тесты
- mypy — статическая типизация
- Poetry — управление зависимостями (опционально)

### Установка и запуск

1. Клонируй репозиторий

   ```bash
   git clone <ссылка на твой репозиторий>
   cd Job_app
   ```
   
2. Создай виртуальное окружение
 ```
python -m venv venv
 ```
3. Активируй его
Windows:
 ```
venv\Scripts\activate
 ```
Linux/Mac:
 ```
 venv\Scripts\activate
  ```
4. Установи зависимости
 ```
pip install -r requirements.txt
 ```
5. (Опционально) Скопируй .env.example в .env
 ```
copy .env.example .env
 ```
(или вручную создай .env и укажи HH_API_BASE_URL=https://api.hh.ru/vacancies)
6. Запусти проект
 ```
python main.py
 ```
